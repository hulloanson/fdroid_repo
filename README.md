# Hacker's Keyboard F-Droid Repository

This repository serves signed Hacker's Keyboard releases for the F-Droid client.

The fork uses package ID `com.hulloanson` and supports Android 8.0 or newer. In English Dvorak portrait mode, the Tab key beside Space is removed and Space takes its width. Landscape and other layouts retain their keys.

To install:

1. In F-Droid, open **Settings > Repositories** and add the repository URL below.
2. Check that F-Droid shows the repository signing fingerprint below, then enable the repository and refresh.
3. Install **Hacker's Keyboard** (`com.hulloanson`), enable it in Android keyboard settings, and select English Dvorak in its language settings.

Future versions use the same app and repository signing keys. F-Droid background updates require a compatible client and Android 12 or newer, with F-Droid configured as the installer/update owner and automatic updates enabled. On other supported Android versions, F-Droid can still offer updates for confirmation.

Source and build instructions: [hulloanson/hackerskeyboard](https://github.com/hulloanson/hackerskeyboard).
